# DOM contract regression

## Trigger

Adding balance metrics introduced new required DOM ids in `src/app/main.ts`, but the matching elements were missing from `index.html`. App startup threw before the first render, leaving the 2D and 3D canvases blank.

## Prevention

- Keep app startup selectors and `index.html` in sync in the same change.
- Add a DOM contract test whenever `requiredElement(...)` gains a new selector.
- Browser-check canvas rendering after UI wiring changes, not only HTTP status.
