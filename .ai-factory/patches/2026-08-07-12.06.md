# Исправление оставшихся blocking issues code review UX-2

**Дата:** 2026-08-07 12:32
**Файлы:** src/app/main.ts, src/modules/rendering/canvas2d.ts, src/modules/rendering/canvas2d.test.ts, src/modules/ui/equipment.ts, src/modules/ui/equipment.test.ts, src/modules/ui/diagnostics.ts, src/shared/safe-id.ts, tests/e2e/import-export.spec.ts
**Серьёзность:** high

## Проблема

После первого раунда исправлений code review выявил 4 оставшихся blocking issues:
1. `renderInteractionViews()` всё ещё вызывал `renderCanvasProfile()`, который вызывает `resizeCanvas()` и полный repaint
2. Selection/hover полностью пересоздавал equipment list через `innerHTML`
3. Interaction render выполнялся даже без фактического изменения state
4. Отсутствовало E2E coverage для UX-2 interaction сценариев

## Корневая причина

1. **Canvas repaint:** `renderCanvasProfile()` объединял resize и полную перерисовку. Interaction path не мог обновить только overlays без resize.
2. **DOM rebuild:** `renderEquipmentEditor()` использовал `innerHTML = ...` для полного пересоздания списка, что разрушало DOM под указателем (pointerout/pointerover циклы) и сбрасывало keyboard focus.
3. **No-op renders:** `setInteractionState()` не сигнализировал об отсутствии изменений, и все handlers безусловно вызывали render.
4. **E2E coverage:** тесты покрывали только import/export/shell — нет проверок selection, navigation, keyboard, focus, camera preservation.

## Решение

### 1. Canvas2D interaction overlay без resize
- Рефакторинг `renderCanvasProfile`: вынесено всё рисование в `drawCanvasProfileContent()`
- `renderCanvasProfile()` = `resizeCanvas()` + `drawCanvasProfileContent()` — для project state изменений
- `renderCanvasInteractionOverlay()` = только `drawCanvasProfileContent()` — для interaction-only обновлений
- Interaction path НЕ вызывает `resizeCanvas()`

### 2. In-place equipment row update
- Добавлена `updateEquipmentRowsInteraction(container, prev, next)` в equipment.ts
- Тогглит CSS классы (`equipment-row--selected`, `equipment-row--hovered`) и атрибуты (`aria-selected`, `data-equipment-selected`) in-place, не пересоздавая DOM
- Skipped если prev === next
- `renderInteractionViews()` использует этот метод, не `renderEquipmentEditor()`

### 3. Guard: render only on actual state change
- Добавлен `prevInteractionState` tracking в main.ts
- `renderInteractionViews()` возвращается сразу если `currentInteraction === prevInteractionState`
- `renderEquipment()` сбрасывает `prevInteractionState` после полного render для синхронизации

### 4. Pure canvas hit-test extraction
- `hitTestEquipmentXz(bodyX, bodyZ, equipment)` вынесен в canvas2d.ts как чистая функция
- Click handler в main.ts использует её через общий transform contract

### 5. Shared safe-id helper
- Создан `src/shared/safe-id.ts` с `safeIdStem(prefix, rawId, index)`
- equipment.ts и diagnostics.ts используют единый helper
- diagnostics больше не зависит от equipment renderer

### 6. E2E coverage
Добавлены 8 Playwright тестов:
- equipment row click → selection + inspector sync
- canvas click selection
- diagnostics entry click → navigation → equipment row selection
- keyboard Enter row selection
- focus preservation after keyboard selection
- selection non-persistence in export JSON
- 3D camera zoom preservation after selection
- hover doesn't rebuild equipment DOM (row count stable)
