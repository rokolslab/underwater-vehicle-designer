# Правила проекта

> Короткие обязательные правила и соглашения для проекта. Автоматически загружаются навыками AI Factory.

## Правила

- Пиши пользователю в чате на русском языке, если он явно не попросил другой язык.
- Используй релевантные AI Factory skills (`aif-*`) для задач, которым они соответствуют; если подходящего skill нет, работай напрямую.
- Всегда используйте инструментарий и навыки AI Factory для планирования, реализации, проверки и сопровождения задач в этом проекте.
- В проекте `ЦВК` означает цилиндрическую вставку корпуса, а `ЦВ` означает центр величины; не используйте `ЦВ` как сокращение для цилиндрической вставки.
- Для полного плана соблюдайте workflow AI Factory: `$aif-plan full` → `$aif-improve` → `$aif-implement` с локальными проверками и checkpoint-коммитами каждые 3–5 связанных задач → итоговый `$aif-verify` → `$aif-review` → при необходимости финальный commit → push → `$aif-archive`; при ошибках выполняйте `$aif-fix` и повторный `$aif-verify`.
- Каждую новую задачу плана или новую независимую задачу выполняйте в новом чате либо отдельным субагентом; текущий чат координирует общий workflow и checkpoint-коммиты.
- В чате с пользователем всегда отвечайте на русском языке.
