## Тест-кейсы: ЦВК внутри общей длины L

---

### TC-001: ЦВК не увеличивает общую длину профиля

**Приоритет:** Высокий
**Тип:** Positive

**Предусловие:** Приложение запущено локально, открыта форма параметров корпуса.

**Шаги:**

1. Установить `L = 6`.
2. Установить `lambda = 3` или убедиться, что `D = 2`.
3. Установить `Lcyl = 2`.
4. Проверить метрики, профиль и ось длины.
5. Экспортировать CSV и SVG.

**Ожидаемый результат:**

Общая длина остается `6`. Последняя станция CSV имеет `x = 6`. SVG содержит ось до `x2="6.000000"`; профиль не растягивается до `8`.

**Тестовые данные:**

```text
L = 6
lambda = 3
D = 2
Lcyl = 2
stations = 20
```

---

### TC-002: Ввод ЦВК больше половины L ограничивается

**Приоритет:** Высокий
**Тип:** Negative

**Предусловие:** Приложение запущено локально, Browser console открыта.

**Шаги:**

1. Установить `L = 6`.
2. Ввести `Lcyl = 4`.
3. Уйти из поля или дождаться обновления состояния.
4. Проверить значение поля ЦВК и консоль.

**Ожидаемый результат:**

Поле ЦВК нормализуется до `3`. У input выставлен `max = 3`. В development-режиме появляется диагностический warn с префиксом `[FIX] cylindrical insert length clamped`.

**Тестовые данные:**

```text
L = 6
Lcyl input = 4
Expected Lcyl = 3
```

---

### TC-003: Отрицательная ЦВК ограничивается нулем

**Приоритет:** Средний
**Тип:** Negative

**Предусловие:** Приложение запущено локально.

**Шаги:**

1. Установить `L = 6`.
2. Ввести `Lcyl = -2`.
3. Проверить значение поля и профиль.

**Ожидаемый результат:**

Поле ЦВК нормализуется до `0`. Профиль соответствует базовой формуле без цилиндрической вставки.

**Тестовые данные:**

```text
L = 6
Lcyl input = -2
Expected Lcyl = 0
```

---

### TC-004: Изменение L пересчитывает максимум ЦВК

**Приоритет:** Высокий
**Тип:** Edge case

**Предусловие:** Приложение запущено локально.

**Шаги:**

1. Установить `L = 8`.
2. Установить `Lcyl = 4`.
3. Изменить `L = 6`.
4. Проверить значение `Lcyl` и атрибут `max` у поля.

**Ожидаемый результат:**

После уменьшения `L` максимум ЦВК становится `3`, значение ЦВК нормализуется до `3`, а профиль заканчивается на `x = 6`.

**Тестовые данные:**

```text
Initial: L = 8, Lcyl = 4
After change: L = 6
Expected: Lcyl = 3, max = 3
```

### TC-005: Regression при Lcyl = 0

**Приоритет:** Высокий
**Тип:** Regression

**Предусловие:** Репозиторий доступен локально.

**Шаги:**

1. Запустить `npm run test`.
2. Проверить тест `matches formula fixture radii`.
3. Проверить тесты station contract при нулевой ЦВК.

**Ожидаемый результат:**

Радиусы по `formula-profile.json` совпадают с fixture. Станции при `L = 6`, `stations = 20` остаются на `0`, `0.15`, `5.85`, `6`.

**Тестовые данные:**

```text
formula-profile.json
Lcyl = 0
```

### TC-006: Canvas 2D и Three.js используют одну длину

**Приоритет:** Средний
**Тип:** Regression

**Предусловие:** Приложение запущено локально с видимыми 2D и 3D представлениями.

**Шаги:**

1. Установить `L = 6`, `Lcyl = 2`.
2. Сравнить 2D-профиль, 3D-корпус и метрику полной длины.
3. Повернуть 3D-сцену и убедиться, что корма остается на конце общей длины.

**Ожидаемый результат:**

2D и 3D визуально согласованы с одной общей длиной `6`. Цилиндрический участок виден внутри корпуса, а не как внешнее удлинение.

**Тестовые данные:**

```text
L = 6
Lcyl = 2
```

## Тестовые данные по техникам тест-дизайна

### Positive

* `L = 6`, `Lcyl = 2`
* `L = 8`, `Lcyl = 4`
* `L = 6`, `Lcyl = 0`

### Negative

* `L = 6`, `Lcyl = 4`
* `L = 6`, `Lcyl = -2`
* `L = bad`, `Lcyl = 2`

### Boundary

* `Lcyl = 0`
* `Lcyl = L / 2`
* `Lcyl = L / 2 + 0.1`
