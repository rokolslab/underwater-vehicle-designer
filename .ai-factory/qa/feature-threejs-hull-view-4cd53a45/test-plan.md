## План тестирования: корректная длина ЦВК внутри L

**Дата:** 2026-07-01
**Branch / Version:** feature/threejs-hull-view
**Окружение:** local Vite / Vitest

---

### 1. Цель тестирования

Проверить, что `L` трактуется как общая длина аппарата, включая ЦВК, а `Lcyl` не увеличивает профиль, станции, SVG/CSV и 3D-представление. Дополнительно проверить ограничение `Lcyl <= L / 2`.

---

### 2. Область тестирования

**В scope:**

- Нормализация пользовательского ввода в `src/app/appState.ts`.
- Расчет профиля в `src/modules/geometry/profile.ts`.
- Станции, smooth points и `snapshot.extents.totalLength`.
- CSV/SVG export по общему `ProfileSnapshot`.
- Ручная smoke-проверка Canvas 2D и Three.js hull view.

**Вне scope:**

- Новая модель оборудования: не реализуется в этом изменении.
- Расчеты ЦТ/ЦВ/баланса: roadmap milestone еще не начат.
- Изменение формулы базового радиуса при `Lcyl = 0`: должно оставаться без изменений.

---

### 3. Типы тестов

| Тип | Приоритет | Область |
| --- | --- | --- |
| Functional | Высокий | `totalProfileLength`, `profileRadiusAt`, `makeStationPoints`, UI clamp. |
| Regression | Высокий | CSV/SVG export, Canvas/3D потребители `ProfileSnapshot`. |
| Edge cases | Средний | `Lcyl = 0`, `Lcyl = L/2`, `Lcyl > L/2`, отрицательный `Lcyl`. |
| Negative | Средний | Некорректный ввод ЦВК и длины. |
| Performance | Низкий | Интерактивное изменение параметров не должно заметно тормозить UI. |

---

### 4. Тестовые данные

| Категория | Данные | Цель |
| --- | --- | --- |
| Валидные данные | `L = 6`, `lambda = 3`, `D = 2`, `Lcyl = 2`, `stations = 20` | Основной сценарий встроенной ЦВК. |
| Граница | `L = 6`, `Lcyl = 3` | Максимально допустимая ЦВК. |
| Невалидные данные | `L = 6`, `Lcyl = 4` | Clamp до `3`. |
| Невалидные данные | `Lcyl = -2` | Clamp до `0`. |
| Regression | `Lcyl = 0` | Совместимость с fixture `formula.xlsx`. |
