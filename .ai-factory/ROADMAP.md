# Дорожная карта проекта

> Underwater Vehicle Designer должен вырасти из статического 2D-калькулятора обводов в модульный браузерный инструмент для 2D/3D-компоновки корпуса подводного аппарата, размещения оборудования и расчета баланса.

## Вехи

- [x] **Восстановить и закрепить корректную русскую кодировку** — привести пользовательские тексты и проектные документы к нормальному UTF-8, чтобы интерфейс и спецификации читались без искажений.
- [x] **Перейти на Vite + TypeScript** — заменить плоский `index.html`/`script.js` на сборку с типизированными модулями, сохранив текущую функциональность.
- [x] **Выделить расчетную геометрию в чистый модуль** — вынести формулу радиуса, станции, экстремумы и сечения из UI-кода в тестируемый `geometry`-слой.
- [x] **Добавить регрессионные тесты по `formula.xlsx`** — зафиксировать численное совпадение ключевых расчетов с табличным источником.
- [x] **Реализовать ЦВК, цилиндрическую вставку корпуса** — добавить `Lcyl` внутри общей длины `L`, ограничение `Lcyl <= L / 2`, непрерывные переходы нос/вставка/корма и обновленные 2D/3D-проекции.
- [x] **Построить 3D-представление корпуса на Three.js** — создать тело вращения, камеру, материалы и интерактивный просмотр геометрии.
- [x] **Добавить модель оборудования и размещение внутри корпуса** — поддержать шар, цилиндр и параллелепипед с координатами, массой, размерами и ориентацией по главным осям.
- [x] **Реализовать проверки ограничений размещения** — блокировать или подсвечивать выход за внутренний объем корпуса и пересечения объектов.
- [x] **Рассчитать ЦТ, ЦВ и баланс** — показывать центр тяжести, центр величины, плавучесть, вес, плечи, крен и дифферент для полностью погруженного аппарата.
- [ ] **Добавить импорт/экспорт проекта** — сохранять и загружать JSON с параметрами корпуса, оборудованием, плотностью воды и расчетными настройками.
- [ ] **Расширить экспорт расчетов и чертежей** — экспортировать координаты обводов, сечения, таблицу оборудования и расчетный блок в CSV/SVG.
- [ ] **Провести финальную QA-проверку интерфейса и расчетов** — проверить типовые сценарии, адаптивность, визуальное соответствие 2D/3D и устойчивость к некорректному вводу.
- [x] **Собрать первичный 2D-прототип обводов** — реализованы статическая страница, расчет формулы, canvas-профиль, таблица станций и экспорт SVG/CSV.
- [x] **Настроить AI Factory context** — созданы описание проекта, архитектурные правила, базовые правила и карта `AGENTS.md`.
