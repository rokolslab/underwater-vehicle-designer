# Underwater Vehicle Designer

> Браузерный инженерный инструмент для построения обводов корпуса подводного аппарата, 3D-просмотра и первичной компоновки оборудования.

Underwater Vehicle Designer помогает быстро проверить форму корпуса, точки обвода, теоретический чертеж, размещение оборудования и базовый баланс по ЦТ/ЦВ. Приложение работает как frontend-only SPA на Vite + TypeScript, использует Canvas 2D для чертежей и Three.js для 3D-сцены.

## Quick Start

```bash
npm install
npm run dev
```

Откройте приложение:

```text
http://127.0.0.1:5173
```

Проверки перед изменениями:

```bash
npm run test
npm run build
npm run check:encoding
```

Docker-вариант:

```bash
docker compose up app
```

## Key Features

- **Размерения корпуса** — длина `L`, удлинение `lambda = L / D`, диаметр `D`, число точек и длина ЦВК.
- **Боковой вид и точки обвода** — Canvas-профиль с сеткой, точками и экспортом SVG/CSV.
- **3D корпус** — Three.js-сцена с режимами `solid`, `x-ray`, `cutaway` и секущими плоскостями.
- **Теоретический чертеж** — профиль, полуширота и корпус в едином масштабе с сечениями, ватерлиниями и батоксами.
- **Оборудование** — сферы, цилиндры и блоки с проверкой выхода за корпус и пересечений.
- **Баланс** — расчет массы, вытесненного объема, веса, плавучести, ЦТ, ЦВ и плеча `ЦВ - ЦТ`.
- **JSON проект** — сохранение и загрузка профиля, оборудования, настроек 3D и настроек баланса.

## Example Workflow

1. Задайте `L = 6`, `lambda = 3`, `D = 2`, `ЦВК = 0`.
2. Проверьте боковой вид и таблицу координат точек.
3. Откройте 3D корпус и выберите режим `Рентген` или `Вырез`.
4. Добавьте оборудование, задайте координаты, массу и размеры.
5. Исправьте строки с предупреждениями `Вне корпуса` или `Пересечение`.
6. Проверьте блок `Баланс` и сохраните проект в JSON.

## Project Status

Текущая версия является инженерным прототипом. Корпус используется как геометрическое ограничение и гидродинамический обвод; плавучесть в актуальном балансовом модуле считается по вытесненному объему оборудования, а не по объему корпуса.
