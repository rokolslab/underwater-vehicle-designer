# Underwater Vehicle Designer

> Браузерный инженерный инструмент для построения обводов корпуса подводного аппарата, 3D-просмотра и первичной компоновки оборудования.

Underwater Vehicle Designer помогает быстро проверить форму корпуса, точки обвода, теоретический чертеж, размещение оборудования и базовый баланс по ЦТ/ЦВ. Приложение работает как frontend-only SPA на Vite + TypeScript, использует Canvas 2D для чертежей и Three.js для 3D-сцены.

## Public Demo v1

`Public Demo v1` — точка остановки для внешнего сайта: главная ценность демо — интерактивная 2D/3D-визуализация корпуса подводного аппарата на ПК и смартфонах. Короткое описание сайта должно вести пользователя сразу к рабочему экрану, а не обещать полноценный CAD или завершенный инженерный расчетный комплекс.

Готовые возможности для публичного демо:

- построение корпуса по режимам `current-formula` и `legacy-dsnp-pa`;
- ввод `L`, `B`, `H`, `lambda`, числа точек и длины ЦВК;
- боковой вид, 3D-сцена, теоретический чертеж и таблица координат;
- базовая компоновка оборудования с предупреждениями о выходе за корпус и пересечениях;
- дополнительный блок баланса по оборудованию;
- импорт/экспорт JSON проекта, SVG/CSV профиля и SVG теоретического чертежа.

Ограничения прототипа: расчет ЦВ герметичного корпуса, инерция, массовые группы, ходкость, энергетика, стоимость, расширенный legacy-импорт и инженерная валидация исторических коэффициентов остаются backlog после публикации сайта.

## Key Features

- **Body/SNAME-NED** — единые инженерные оси: X к носу, Y на правый борт, Z вниз; начало в центре корпуса.
- **Режимы геометрии корпуса** — `current-formula` по умолчанию и `legacy-dsnp-pa` как DSNP_PA regression/traceability mode с эллиптическими сечениями первого slice.
- **Размерения корпуса** — длина `L`, удлинение `lambda = L / H`, ширина `B`, высота `H`, число точек и длина ЦВК (цилиндрической вставки корпуса).
- **Боковой вид и точки обвода** — Canvas-профиль с сеткой, точками и экспортом SVG/CSV.
- **3D корпус** — Three.js-сцена с режимами `solid`, `x-ray` и независимыми секущими плоскостями.
- **Теоретический чертеж** — профиль, полуширота и корпус в едином масштабе с сечениями, ватерлиниями и батоксами.
- **Оборудование** — сферы, цилиндры и блоки с проверкой выхода за корпус и пересечений.
- **Баланс** — ЦТ, equipment-only ЦВ, `deltaX`, `deltaY`, `BG` и моменты в Body/NED.
- **JSON проект** — сохранение и загрузка профиля, оборудования, настроек 3D и настроек баланса.

## Example Workflow

1. Выберите режим геометрии и задайте `L = 6`, `lambda = 3`, `B = 2`, `H = 2`, `ЦВК = 0`.
2. Проверьте боковой вид и таблицу координат точек.
3. Откройте 3D корпус, выберите режим `Рентген` и при необходимости включите `Сечение`.
4. Добавьте оборудование, задайте координаты, массу и размеры.
5. Исправьте строки с предупреждениями `Вне корпуса` или `Пересечение`.
6. Проверьте блок `Баланс` и сохраните проект в JSON.

## Project Status

Текущая версия является инженерным прототипом. Корпус используется как геометрическое ограничение и гидродинамический обвод; legacy DSNP_PA режим нужен для регрессии/traceability, а не для подтверждения инженерной валидности исторических коэффициентов. Плавучесть в актуальном балансовом модуле считается по вытесненному объему оборудования, а не по объему корпуса.
