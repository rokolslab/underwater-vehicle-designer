# ТЗ: 3D-компоновка подводного аппарата по обводам

## Summary

Сделать клиентский веб-сайт для построения объемного проницаемого корпуса-обтекателя по текущей формуле обвода, добавления цилиндрической вставки в зоне максимального радиуса, размещения оборудования внутри корпуса и расчета ЦТ/ЦВ/крен-дифферента.

Корпус не дает плавучесть сам по себе: он служит гидродинамическим обводом и ограничивает размещение. Центр величины считается по объему воды, вытесненному размещенным оборудованием.

Термины: `ЦВК` — цилиндрическая вставка корпуса, длина вставки в метрах; `ЦВ` — центр величины в расчетах баланса. Эти сокращения не взаимозаменяемы.

Инженерный контракт использует Body/SNAME-NED с началом в центре корпуса: `+X` к носу, `+Y` на правый борт, `+Z` вниз. Профиль хранит `s=0..L` от носа к корме (`body.x=L/2-s`). Three.js и Canvas/SVG используют adapters. JSON v2 маркируется `SNAME_NED_BODY_CENTER_V1`; v1 мигрирует с предупреждением `old.z=starboard`.

## Key Changes

- Перевести проект на модульную структуру с `Vite + TypeScript + Three.js`.
- Исправить текущую кодировку/русский текст в HTML/JS.
- Геометрия корпуса:
  - `L` — общая длина аппарата, включая ЦВК;
  - `0 <= Lcyl <= L / 2`;
  - расчетная длина гладкой носо-кормовой части: `Lsource = L - Lcyl`;
  - исходный радиус гладкой части: `r(s) = 0.972 * D * sqrt((s/Lsource) * (1 - s/Lsource) * (1 - 0.5*s/Lsource))`;
  - `D = L / lambda`;
  - максимальное сечение гладкой части: `xMax = Lsource * (1 - sqrt(3)/3)`;
  - ЦВК, цилиндрическая вставка длиной `Lcyl`, размещается после `xMax` внутри общей длины `L`;
  - итоговая длина профиля: `Ltotal = L`;
  - корпус считается телом вращения вокруг оси `x`.
- Интерфейс:
  - 2D вид сбоку Body XZ;
  - 2D вид сверху Body XY;
  - поперечное сечение Body YZ;
  - 3D-превью корпуса и оборудования;
  - таблица оборудования и расчетный блок.

## Equipment And Constraints

- Типы оборудования:
  - шар: радиус, масса, позиция `x/y/z`;
  - цилиндр: радиус, длина, масса, позиция `x/y/z`, ось `X/Y/Z`, дефолт `X`;
  - параллелепипед: размеры `lengthX/breadthY/heightZ`, масса, позиция `x/y/z`.
- В первой версии оборудование ориентировано по главным осям корпуса, без произвольных углов поворота.
- Для каждого объекта считать:
  - массу;
  - геометрический объем;
  - собственный центр;
  - вытесненный объем воды, по умолчанию равный геометрическому объему объекта.
- Ограничения:
  - объект не может выходить за внутренний объем корпуса-обтекателя;
  - объекты не могут пересекаться между собой;
  - при нарушении ограничения перемещение блокируется или объект подсвечивается как недопустимый.

## Calculations

- Допустимый объем корпуса:
  - в станции `x`: `y^2 + z^2 <= r(x)^2`;
  - для продольного сечения при `z = z0`: `y = +/-sqrt(r(x)^2 - z0^2)`;
  - для горизонтального сечения при `y = y0`: `z = +/-sqrt(r(x)^2 - y0^2)`.
- Центр тяжести оборудования:
  - `G = sum(m_i * p_i) / sum(m_i)`.
- Центр величины:
  - корпус не участвует в плавучести;
  - `B = sum(V_i * p_i) / sum(V_i)`, где `V_i` - объем воды, вытесненный оборудованием;
  - сила плавучести: `Fb = rho * g * sum(V_i)`.
- Вес:
  - `W = sum(m_i) * g`.
- Баланс:
  - показывать `Fb - W`;
  - показывать координаты `G` и `B`;
  - показывать плечо между `G` и `B` по `x/y/z`.
  - показывать `deltaX`, `deltaY`, `BG` и моменты в Body/NED;
  - явно указывать, что текущий ЦВ рассчитан только по вытесненным объемам оборудования и не является ЦВ внешнего герметичного корпуса.
- Крен и дифферент:
  - считать для полностью погруженного аппарата;
  - крен и дифферент определять по взаимному положению центра тяжести и центра величины оборудования;
  - если центр величины не выше центра тяжести в выбранной системе координат, показывать предупреждение о неустойчивой компоновке.

## Export And Persistence

- Сохранять проект в JSON: параметры корпуса, список оборудования, масса, размеры, координаты, плотность воды.
- Импортировать JSON обратно.
- Экспортировать:
  - координаты обводов и сечений в CSV;
  - 2D-чертеж в SVG;
  - таблицу оборудования и расчетов в CSV.

## Test Plan

- Регрессия формулы: при `L=6`, `lambda=3`, `D=2`, `Lcyl=0` ординаты совпадают с `formula.xlsx`.
- Геометрия вставки: радиус на цилиндрическом участке постоянный, переходы нос/вставка/корма непрерывные.
- Сечения: продольные и поперечные сечения дают корректные границы при разных `x/y/z`.
- Размещение: шар, цилиндр и параллелепипед не выходят за корпус и не пересекаются.
- ЦТ: при изменении массы объекта `G` смещается пропорционально массе.
- ЦВ: при изменении объема объекта `B` смещается пропорционально вытесненному объему, а не массе.
- Баланс: `Fb - W` корректно меняется при изменении плотности воды, массы и размеров объектов.
- UI: перемещение объектов обновляет 2D виды, 3D-превью, таблицу, ЦТ, ЦВ, крен и дифферент.

## Assumptions

- Единицы: метры, килограммы, плотность воды `1025 kg/m^3` по умолчанию.
- Корпус проницаемый и используется только как гидродинамический обвод/ограничивающий объем.
- Все оборудование по умолчанию вытесняет воду своим геометрическим объемом.
- Масса корпуса, балласт, переборки, толщина обшивки и частично затопляемые объемы в первую версию не входят, но модель данных должна позволять добавить их позже.
